# B 数据集分析脚本（预置经验的证据来源）

2026-11-23 在公开数据上做的分析，只读官方 B 包（训练 9 根、验证 3 根轴承），不调用大模型。
预置经验 `team_sim/seeds.json` 里的 `evidence_ids` 对应下表。数字来自当时的本机运行（NumPy 1.26.4），重跑应一致。

运行方式（在项目根目录）：

```bash
python -I team_sim/evidence/analyze_b7.py "$PWD" /path/to/cpu-b-package
python team_sim/evidence/run_continuation.py "$PWD" /path/to/cpu-b-package /tmp/cont-runs
```

| 脚本 | 回答的问题 | 主要结果 | 证据编号 |
|---|---|---|---|
| analyze_b.py | 混合工况是不是主要问题？ | 已知工况时留一根轴承误差明显下降（常数 793→333）；但只靠振动特征认不出新轴承的工况（20%–55%） | — |
| analyze_b2.py | 特征能分清什么？ | 见过的轴承能认出（95%）；新轴承的寿命长短认不出（6%）；最后 20% 寿命段平均 AUC 0.71 | — |
| analyze_b3.py | 只用形状/频率特征会不会更好？ | 指纹仍在（70% vs 74%），留一根轴承误差 735→705，无本质改善 | — |
| analyze_b4.py | 哪些特征跨轴承通用？基线依赖哪些？ | 幅值/能量类在寿命末段普遍上升（AUC≈0.9）；打乱频谱质心、峭度、功率谱峭度后按行 RMSE 反降 19–28 | sim-b4 |
| analyze_b5.py | 健康期能否给参考范围？ | 健康期特征与寿命无关；相似快照给出的范围或极宽或错（与真实寿命秩相关 −0.51） | — |
| analyze_b6.py | 健康期能否提升（简单模型）？ | 健康段用特征比常数更差；退化段特征有用 | — |
| analyze_b7.py | 截断目标在 MLP 上（从头训练） | 按行/等权 652/408 → 上限≈1146 时 617/391 | sim-b7 |
| analyze_b8.py | 上限怎么取 | 954（全部标签均值）与 1145 按行相同、等权略好；取小值偏向短寿命轴承 | sim-b8 |
| run_continuation.py | 从官方检查点续训时是否仍有效 | 续训 15 轮按行 653→632，最后 20% 段 499→237；健康段几乎不变 | sim-cont |

其余编号：`pkg-hist` = 官方包 history.jsonl（验证 RMSE 第 2 轮 567、第 15 轮 681）；`pkg-val` = 官方验证集组成（1679 行中 1515 行来自 Bearing3_4）；`design-05`、`design-06` = 设计讨论，无单独实验。
