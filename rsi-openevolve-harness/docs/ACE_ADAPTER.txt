最小操作
先进入项目根目录 /home/captain/projects/FINAL/rsi-openevolve-harness；下文 python 均指上面的共享环境解释器。
python -m team_ace init
  本次合并已建立 A/B/C 配置，无须再初始化；此命令用于全新副本，不覆盖现有配置。
python -m team_ace status --config configs/run_A.json
python -m team_ace flush --config configs/run_A.json
  从同学框架的 iterations.jsonl 补处理尾批/遗漏回调，可重复执行，不会重复记录。

  处理最多一个队列任务；默认正式配置 mode=disabled，不调用模型。
python -m team_ace serve --config configs/run_A.json --max-jobs 3 --seconds 60
  有限时间处理队列，可与搜索并行；退出后不会留下常驻服务。

A/B/C 分开管理
state/live/A/<scope>/、state/live/B/<scope>/、state/live/C/<scope>/ 是正式目录。
scope 绑定数据、起点检查点的 SHA-256、任务类型/单位、划分与评分配置。
换数据、起点、划分或指标配置后应新建配置与目录，旧经验默认不复用；不将不同条件混为事实。
每份目录有 memory.sqlite3（证据、队列、候选、调用记录）、playbook.md、view.json 和 versions/。
用户不需要手动编辑数据库；也不要把测试目录的文件复制到正式目录。

可信性边界
每条经验只能处于 candidate（待验证）或 retired（停用）；模型不能自行宣称已验证。
保存实测结果与假设的区别，拒绝无来源的经验、虚构实验 ID、跨任务记录和 gate/test 反馈。
记录按 run_id、stage_id、task、iteration、program_id、kind 去重；同一标识冲突会报错。
同一建议合并已有证据，失败/退化结果保留；结果关联不被当成因果贡献。
模型自报 helpful/harmful 标签只留作原始输出，不据此给经验升级或加分。
原始记录中的 used_bullets 仅保留审计用途，本版没有宣称实现可靠的条目贡献归因。
本版以精确规范化文本去重，不声称实现语义去重。
输出不超过 1900 字符，低于队友提示的 2500 字符限额；完整历史保存在数据库。
最终验收/隐藏测试的结果不能送回经验生成；本版不会自动执行效果验证或升级技能。

恢复和回退
回调落盘与入队是一个事务；工作进程失败不会丢失实验记录。
python -m team_ace retry --config configs/run_A.json
  手动恢复失败任务；每任务最多两次尝试，失败调用仍占总预算。
python -m team_ace retire --config configs/run_A.json --entry-id A-某个编号
  停用候选，保留历史证据。
python -m team_ace rollback --config configs/run_A.json --version 已有的12位版本号
  恢复该任务/条件下的旧经验版本，不删除实验和调用记录。
python -m team_ace render --config configs/run_A.json
  从数据库修复中断后尚未更新的经验文件。

资源和模型预算
每次 CLI 最多 3 个工作任务，每任务最多两次角色调用；整次 process/serve 有截止时间。
子进程墙钟上限通常 35 秒；监测 RSS 超过 384 MiB 或系统可用不足 250 MiB 时终止进程组。
内存监测是采样停止机制，不是任意代码安全沙箱或操作系统硬内存配额。
每个任务/条件目录有持久化的 max_total_calls；失败也计数，传输层不自动重试。
真实模式要求显式 endpoint、model、api_key_env、live_calls_approved，默认全部关闭/未配置。
每次输出上限 1024 tokens，输入有字符上限并保存提供方实际 usage；字符限制不是 Qwen 总 token 硬限额。
首次收费调用前仍需确认实际模型、价格、额度和总 token 预算；本次没有产生模型费用。
