# 比赛镜像 v1.2.1 改动说明（2026-11-27）

镜像标签 `zhixun-rsi:v1.2.1`，直接上传 `zhixun-rsi-v1.2.1.tar`（193,351,680 字节，Windows 资源管理器显示 188,820 KB；SHA256 见 `SHA256SUMS`）。训练逻辑和 v1.2 完全相同，只修了一个启动时的问题。

## 修了什么
v1.2 的试运行在"入口预检"时失败：`/app/harness.py`（SDK 入口文件）和 `/app/rsi/harness/`（我们的代码包）同名。
v1.2 只在路径"还不存在"时才把 `/app/rsi` 和 `/app` 插进 Python 的查找路径。用 `python3 /app/harness.py` 正常启动时，`/app` 本来就排在最前，所以顺序是对的，v1.1 的试运行因此能跑通。平台这次换了一种加载方式，`/app` 事先不在路径里，结果 `/app` 排到了最前，`import harness` 拿到的是入口文件，训练一开始就失败了。

现在的做法：每次都强制把 `/app/rsi` 放在最前，`/app` 放在它后面；如果入口文件已经以 `harness` 这个名字被加载过，先把它清掉。

## 测试
新增两个测试，复现平台预检的两种加载方式：`/app` 事先不在路径里；入口文件已经以 `harness` 名字被加载。旧的 v1.2 代码上这两个测试都失败，修复后通过。用从镜像里解出的 `/app` 跑全部 11 个适配器测试，全部通过。
